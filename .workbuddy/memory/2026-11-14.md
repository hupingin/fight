## 星际战机 Star Raider（Godot 4 竖版打飞机，纯本地）

按 `需求.md` 完成整套游戏，工程根目录 `E:/xxx/tmp/003.WorkBuddyDemos/022.fightGame`。

### 结构
- `project.godot`：540x960 竖屏，gl_compatibility，Autoload = SaveManager / AudioManager / GameState，主场景 main_menu.tscn
- `data/bullets.json` + `data/enemies.json` + `data/levels/level_01..04.json`：全数据驱动，含 goal / enemy_pool / spawn_interval / hp_multiplier / waves 波次表 / boss 多阶段
- `scripts/autoload/`：save_manager（user://save_data.json，JSON，容错 + 重置）、audio_manager（总线音量/开关）、game_state（跨场景关卡参数）
- `scripts/entities/`：player（无敌帧闪烁）、player_bullet、enemy（4 类攻击模式）、enemy_bullet、boss（血量分段切阶段）
- `scripts/fx/`：space_bg（程序化背景，按关卡换色调）、starfield、explosion（粒子）
- `scripts/ui/`：ui_kit（统一控件工厂）、hud、main_menu（内含设置面板：音量/音效开关/屏幕震动/重置存档）、level_select（锁定/已解锁/已通关三态）
- `tools/screenshot.tscn + screenshot.gd`：开发期截图自查工具，支持 `--scene --level --hold=KEY --killall --click=x,y --wait --out`

### 关键实现 / 踩过的坑
- Autoload 实例化顺序：game.gd 用 `_ready` 里 `call_deferred` 起关，避免在第一帧物理回调里建碰撞体（曾报 "Can't change this state while flushing queries"）。
- `SaveManager._merge()` 早期只遍历默认结构的 key，导致默认值为空字典的 `level_records` 读档时被整段丢弃（表现为已通关关卡显示"尚无记录"、已通关 0/4）。改为遍历 incoming 并采纳未知 key 后修复。
- 设置面板打开时隐藏主菜单底部的"历史最高分/版本号"小字，否则会透过半透明面板。
- Boss 血条放在 HUD 顶部 y=58 区域、宽度 400，避免压住 Boss 机体。

### 验证方式
headless 截图逐屏确认：主菜单 / 选关三态 / 战斗 / Boss 战 / 暂停 / 失败结算 / 通关结算（A 评价）/ 设置面板；并用新进程重开验证读档（已通关 1/4、最高分记录、解锁下一关）。窗口模式 `--quit-after 240` 退出码 0。退出时只有 Godot 自身的 ObjectDB/resource leak 提示（截图工具立即 quit 导致，非游戏逻辑错误）。

## 追加需求：每关三档难度（容易 / 中等 / 困难）

- `data/difficulties.json` 定义倍率：enemy_hp / enemy_speed / spawn_interval / enemy_fire_interval / enemy_bullet_speed / boss_hp / boss_fire_interval / boss_bullet_speed / damage_taken / score。容易 0.7 血、更稀弹幕、得分 ×0.8；困难 1.45 血、射速更快、承伤 ×1.25、得分 ×1.25。
- `LevelData` 增加 difficulty() / difficulty_ids() / difficulty_label() / difficulty_color()，未知 id 回退 normal。
- `GameState.difficulty` + `start_level(level_id, diff)`；重试/进入下一关沿用当前难度。
- 存档改为按难度分桶：`level_records["1"]["normal"] = {high_score, cleared}`；`level_record(level_id, difficulty)` 兼容旧版单层结构（自动识别并迁移到 normal）。解锁规则：任意难度通关即解锁下一关。
- 选关界面顶部加「难度」切换器（三个按钮，选中态用难度色描边），切换后重建卡片按当前难度显示记录；选择写入 settings.last_difficulty。主菜单「开始游戏」沿用上次难度，并显示「当前难度」提示行。
- HUD 右上、开局 banner、结算面板标题都带难度标签；玩家承伤在 `player.take_damage` 里乘 damage_taken。
- 截图工具新增 `--difficulty=easy|normal|hard`。
- 踩坑：GDScript 里 `var selected := id == _difficulty`（id 来自 Array，类型是 Variant）会报 "Cannot infer the type" 导致整个脚本 Parse Error、界面全黑，必须显式写 `var selected: bool =`。
